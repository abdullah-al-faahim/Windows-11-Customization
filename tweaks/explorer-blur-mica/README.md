# ExplorerBlurMica

Adds a blur / Mica background to File Explorer. Project: [Maplespe/ExplorerBlurMica](https://github.com/Maplespe/ExplorerBlurMica) (LGPLv3).

**Install:** keep this folder somewhere permanent (e.g. `C:\Tools\ExplorerBlurMica`), then right-click `register.cmd` → **Run as administrator**. Explorer restarts with the effect.

**Configure:** edit `config.ini`. `effect=1` is Acrylic; `2` Mica, `4` MicaAlt. The `[light]` / `[dark]` sections set the tint color and alpha. Restart Explorer after changes.

**Remove:** run `uninstall.cmd` as administrator.
