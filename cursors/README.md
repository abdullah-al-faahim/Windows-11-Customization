# Cursors

| Folder | Pack |
|---|---|
| `catppuccin-mocha/` | Catppuccin Mocha cursors in 16 accents (for dark themes) |
| `catppuccin-latte/` | Catppuccin Latte cursors in 16 accents (for light themes) |
| `macos-tahoe/` | macOS Tahoe cursor with shadow |

**Install:** open a pack folder → right-click `install.inf` → **Install** (on Windows 11 choose **Show more options** first). Then **Settings → Bluetooth & devices → Mouse → Additional mouse settings → Pointers**, pick the scheme and press **Apply**.

Catppuccin cursors come from [catppuccin/cursors](https://github.com/catppuccin/cursors).
