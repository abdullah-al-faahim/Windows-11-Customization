# Fastfetch

Catppuccin-colored [Fastfetch](https://github.com/fastfetch-cli/fastfetch) layout with a custom ASCII logo.

**Install:** copy `config.jsonc` and `ascii.txt` to `%USERPROFILE%\.config\fastfetch\`. Then edit `logo.source` in `config.jsonc` so it points at your own user folder (it currently says `C:/Users/Fahim Rifat/...`).
