# PowerShell profile

A merged profile based on [ChrisTitusTech/powershell-profile](https://github.com/ChrisTitusTech/powershell-profile): UTF-8 console, handy aliases and helper functions.

**Install:** run `notepad $PROFILE` in PowerShell 7, paste the contents of `Microsoft.PowerShell_profile.ps1`, save and restart the shell.

[`winhance.md`](winhance.md) has the one-liner for [Winhance](https://github.com/memstechtips/Winhance), a debloat and tweak utility. Read any script before piping it into `iex`.
