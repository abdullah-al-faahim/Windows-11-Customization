# Visual Studio Code

Editor settings (Prettier, format on save, bracket guides, Live Server / Live Sass) plus the Catppuccin theme extension.

**Install:**
1. Extensions view → `···` → **Install from VSIX…** → pick `catppuccin-vsc-3.18.1.vsix`.
2. `Ctrl + Shift + P` → **Preferences: Open User Settings (JSON)** → merge in `settings.json`.
