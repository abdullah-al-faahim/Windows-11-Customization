# GlazeWM

Tiling window manager config with 8px gaps, Windows 11 focus borders and vim-style keys.

**Install:** [GlazeWM](https://github.com/glzr-io/glazewm) → copy `config.yaml` to `%USERPROFILE%\.glzr\glazewm\config.yaml` → press `Alt + Shift + R` to reload.

| Keys | Action |
|---|---|
| `Alt + H/J/K/L` or arrows | Focus window |
| `Alt + Shift + H/J/K/L` | Move window |
| `Alt + 1…9` / `Alt + Shift + 1…9` | Go to / send to workspace |
| `Alt + R` | Resize mode (`Esc` to exit) |
| `Alt + F` / `Alt + T` / `Alt + M` | Fullscreen / toggle tiling / minimize |
| `Alt + Shift + Space` | Toggle floating |
| `Alt + V` | Flip tiling direction |
| `Alt + Enter` | Open Windows Terminal |
| `Alt + Shift + Q` | Close window |
| `Alt + Shift + P` / `R` / `E` | Pause / reload / exit GlazeWM |
