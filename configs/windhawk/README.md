# Windhawk mods

Settings for five [Windhawk](https://windhawk.net/) mods that slim down and restyle the taskbar.

| File | Mod |
|---|---|
| `windows-11-taskbar-styler.json` | Windows 11 Taskbar Styler |
| `taskbar-height-and-icon-size.json` | Taskbar height and icon size (36px bar, 16px icons) |
| `taskbar-labels.json` | Taskbar Labels |
| `taskbar-volume-control.json` | Taskbar Volume Control (scroll to change volume) |
| `windows-11-notification-center-styler.json` | Windows 11 Notification Center Styler (TranslucentShell theme) |

**Apply:** install the mod in Windhawk → **Details → Advanced → Mod settings** → paste the file contents → **Save**.
