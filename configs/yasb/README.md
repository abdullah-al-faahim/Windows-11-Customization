# YASB (Yet Another Status Bar)

Top bar with blur: home menu, taskbar and media on the left, clock in the center, tray, network traffic, volume and power menu on the right.

**Install:** [YASB](https://github.com/amnweb/yasb) → copy `config.yaml` and `styles.css` to `%USERPROFILE%\.config\yasb\`. YASB watches both files and reloads on save.

Needs a [Nerd Font](https://www.nerdfonts.com/) (JetBrainsMono Nerd Font) for the icons. Earlier versions of the config live in [`old/`](old).
