# Discord theme

One-line import of the [Catppuccin Mocha](https://github.com/catppuccin/discord) Discord theme.

**Install:** needs a client mod such as [Vencord](https://vencord.dev/) or [BetterDiscord](https://betterdiscord.app/). Open **Settings → QuickCSS** (or Custom CSS) and paste the contents of `catppuccin-mocha.css`.
